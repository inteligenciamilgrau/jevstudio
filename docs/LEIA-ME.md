# docs/

Imagens do README.

## `jevstudio.png` — a imagem de demonstração

O README aponta para `docs/jevstudio.png` logo abaixo do primeiro parágrafo.
**Enquanto o arquivo não existir, o GitHub mostra um ícone de imagem quebrada**
no lugar. Coloque o arquivo aqui com esse nome exato (minúsculo, `.png`).

### O que vale mostrar

A imagem é a primeira coisa que alguém vê. A tela que explica o projeto em um
olhar é a bancada rodando:

- o funil à esquerda, com pelo menos um nó aberto mostrando as perguntas
- os fios coloridos com as porcentagens — é o que diferencia este projeto
- o monitor à direita com uma decisão recente no log

Uma captura com o piloto rodando vale mais que uma tela parada, porque os
números aparecem.

### Tamanho

Largura entre 1200 e 1600 px. O GitHub reduz para a largura do README, então
acima disso só pesa o clone. Tente ficar abaixo de 1 MB.

> Confira antes de subir: a bancada mostra a URL do jogo, nomes de funil e o
> log de decisões. Nada disso costuma ser sensível, mas a captura pega a tela
> inteira — inclusive o que estiver atrás dela.
